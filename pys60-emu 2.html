PyS60 Emulator

drop a Python 2 PyS60 script, it gets converted and runs in your browser Loading runtime…
This page needs WebAssembly JSPI (Chrome / Edge / Chromium-based browsers, version 137+). Firefox and Safari can't run blocking dialogs yet.

Script

Upload the main script plus any local modules it imports. Python 2 source is converted with 2to3 in the page. e:\ / c:\ paths map to a virtual drive saved in this browser.

Network & storage settings

Raw TCP sockets don't exist in a browser tab; httplib, urllib and urllib2 are routed to the transport above. Responses are fully buffered before the script sees them.
